# 📁 FileSorter

A lightweight, fast, and automated tool designed to clean up cluttered directories (such as Downloads or Desktop) with a single click and organize files based on customizable rules.

---

## ✨ Features

- **⚡ One-Click Organization:** Clean up target folders instantly.
- **🏷️ Flexible Sorting Criteria:**
  - **By File Type:** Automatically sorts into categories such as `Images`, `Documents`, `Videos`, `Audio`, `Archives`, or `Executables`.
  - **By Date:** Organize files by Year/Month using creation or modification dates.
  - **By File Extension:** Map custom extensions (e.g., `.pdf`, `.docx`, `.png`) to designated folders.
- **🔍 Dry-Run Preview Mode:** Preview intended file operations without making actual changes to the filesystem.
- **↩️ Undo Functionality:** Revert the last sorting operation with one click.
- **🔒 100% Local & Private:** No cloud connection, no telemetry—all processing stays on your local machine.
